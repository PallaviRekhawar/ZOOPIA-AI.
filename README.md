# 🦁 ZOOPIA AI - Intelligent Zoo Management System

[![License: MIT](https://img.shields.io/badge/License-MIT-green.svg)](https://opensource.org/licenses/MIT)
[![PHP Version](https://img.shields.io/badge/PHP-8.2-blue.svg)](https://php.net)
[![XAMPP](https://img.shields.io/badge/XAMPP-3.3.0-orange.svg)](https://www.apachefriends.org)

**ZOOPIA AI** is a web-based zoo management system that automates administrative operations and enhances visitor experience with **AI-powered features**. Built with PHP, MySQL, HTML, CSS, and JavaScript, it includes an AI chatbot, TensorFlow.js animal identifier, facts generator, and voice search.

---

## ✨ Features

### 🔐 Admin Authentication
- Secure login with session management
- Default credentials: `pallavi` / `pallavi`

### 📊 Zoo Management Modules
- 🦁 **Animal Management**: Add, view animals with photo upload
- 🎫 **Ticket Booking**: Online booking with GST calculation & token generation
- 👥 **Visitor Tracking**: Register walk-in visitors
- 📧 **Inquiry Management**: Handle visitor questions
- 👷 **Staff Management**: Maintain staff records

### 🤖 AI-Powered Features
- 🤖 **AI Chatbot**: Instant answers about animals, tickets, timings
- 📸 **AI Animal Identifier**: Upload photo → TensorFlow.js identifies animal
- 🔮 **AI Facts Generator**: Random educational animal facts
- 🎤 **Voice Search**: Speak to find animals hands-free
